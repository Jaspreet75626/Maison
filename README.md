# MAISON — Multi-Page E-Commerce Website

A fully functional luxury fashion e-commerce website built from scratch 
using HTML, CSS, and Vanilla JavaScript. No frameworks or libraries used.

## Pages
- **Shop** — Product listing with filters, sorting, and cart drawer
- **Product Detail** — Size selector, colour swatches, accordion info, related products
- **Checkout** — Form validation, promo codes, and order confirmation

## Features
- Dynamic filtering by category, colour, price range, and status
- Persistent shopping cart using localStorage (survives page refresh)
- Slide-in cart drawer with live quantity controls and subtotal
- Real-time form validation with auto card-type detection
- Fully responsive — mobile sidebar collapses to a drawer
- Shared `data.js` module as single source of truth across all pages

## Tech Stack
| Technology | Usage |
|---|---|
| HTML5 | Page structure and semantic layout |
| CSS3 | Styling, animations, Grid, Flexbox |
| JavaScript (ES6+) | Filtering, cart logic, DOM manipulation |
| localStorage API | Cart persistence across pages |

## How to Run
1. Download or clone the project
2. Unzip the folder
3. Open `index.html` in any browser
4. No installation or server required
